## 🍔 FoodHub – Frontend Application

FoodHub is a modern food ordering frontend application built with **Next.js**.  
The platform allows users to browse meals, view detailed food information, and enables admins/providers to manage meals efficiently through a clean and responsive dashboard.

## 🧑‍💻 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, ShadCN UI
- **Icons:** Lucide React
- **State Management:** React Hooks
- **Notifications:** Sonner Toast
- **Authentication:** Cookie-based (via backend)
- **API Communication:** Fetch API
- **Image Handling:** Next.js Image Component

---

## ✨ Key Features

### 👤 User Features

- Browse available meals
- View detailed meal information
- Responsive UI for all devices
- Smooth navigation and clean design

### 🛠️ Admin / Provider Features

- Create new meals
- Upload multiple meal images
- Manage meal categories
- Set price, stock, availability, and dietary type
- Protected dashboard routes
- Role-based access control
